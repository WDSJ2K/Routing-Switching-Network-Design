# Routing, Switching & Network Design Portfolio

This repository documents hands-on networking labs focused on **routing, switching, and foundational network design** concepts aligned with **CCNA-level objectives**.

The work emphasizes **how networks are built**, configured, and validated in small enterprise-style environments using **Cisco IOS–based devices**. These labs represent baseline configurations and design foundations that support higher-level operations and troubleshooting.

---

## 📁 Repository Structure

### configs/
Device configuration files used to implement routing, switching, and segmentation concepts, including:
- Interface configuration
- VLAN creation and assignment
- IP addressing
- Basic routing configuration

Configs are scoped to the lab objective and represent **intentional design choices**, not full production templates.

---

### diagrams/
Logical and physical network diagrams illustrating:
- Device relationships
- Interface connectivity
- VLAN and network segmentation
- Routing paths

Diagrams provide visual context for each lab’s design.

---

### validation/
Command output and test results used to confirm expected behavior, such as:
- Interface and IP status checks
- VLAN verification
- Routing table validation
- Connectivity testing (ping, traceroute)

This folder demonstrates that configurations were **verified**, not just applied.

---

## 🎯 Focus Areas

- Switching fundamentals (VLANs, access/trunk concepts)
- IP addressing and subnetting
- Inter-VLAN routing
- Basic routing concepts
- Network segmentation and design validation
- Cisco IOS configuration and verification
